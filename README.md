An offline guide and tracker for the 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words with its sources cited, a roadmap to the platinum, missable flags, and a checklist whose progress is saved in the browser and can be exported and imported.

## Play it

Serve the `app/` folder with any static server, then open `index.html` in a desktop browser:

```sh
cd app && python3 -m http.server 8080
```
