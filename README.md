Leonida Trophy Guide is an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words with its sources named, a five-stage roadmap to the platinum with the missable trophies flagged, and a checklist whose progress is saved in the browser and can be exported and imported.

## Run it

Serve the `app/` folder with any static server, then open `index.html` in a desktop browser. No build step, no network:

```sh
cd app && python3 -m http.server 8080
```

Click a trophy to open its guide beside the checklist. Use the kind and grade filters, the search box, and the spoiler setting — it hides story trophies until they are earned.
