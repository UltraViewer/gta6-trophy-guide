Leonida Trophy Guide is an offline companion for hunting every PlayStation 5 trophy in Grand Theft Auto VI. It lists all 55 trophies with their official name, description and grade, and pairs each one with a guide written in our own words plus the sources it was drawn from, named by site (Exophase GTA 6 trophy guide and PSNProfiles GTA 6 Trophy Guide). A five-stage roadmap lays out the path to the platinum, flagging the trophies that can be missed along the way. The checklist keeps your progress in the browser, so you can tick trophies off as you earn them, export that progress to a file, and import it back later. Kind, grade and search filters narrow the list to what you are working on, and a spoiler setting keeps story trophies hidden until you have earned them.

## Run it

Serve the `app/` folder with any static server, then open `index.html` in a desktop browser. No build step, no network:

```sh
cd app && python3 -m http.server 8080
```

Click a trophy to open its guide beside the checklist. Use the kind and grade filters, the search box, and the spoiler setting — it hides story trophies until they are earned.
